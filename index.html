DOCTORAL THESIS GAMES UX N = 117 ADULT SAMPLE

Cognitive Flow & Usability in Creative Sandbox Environments

Evaluating How Interface Usability Drivers Impact Player Immersion and Altered Time Perception

Investigated the bidirectional relationship between UI ergonomics in Minecraft: Creative Mode and player cognitive states. Applied quantitative Pearson correlation models to isolate which interface features actively facilitate temporal distortion and uninterrupted creative flow.

KEY DATA INSIGHT: r = 0.74 (Strong Positive Signal)
Inventory management ease demonstrated the strongest correlation with player flow state. Reducing friction in item retrieval directly prolonged uninterrupted cognitive immersion.

Taíno Language Learning & Gamified Retention

Designing Accessible Learning Loops for Endangered Cultural Language Acquisition

Led research cycles to design a gamified mobile experience for learning modern Taíno. Evaluated player motivation models to replace static vocabulary lists with active speaking practice and milestone reward loops.

KEY DATA INSIGHT: 72.2% Active Learning Demand
72.2% of users requested active speaking challenges over passive reading. 83.0% prioritized milestone-based progression for sustained long-term motivation.

1. Interface Ergonomics

Streamlined hotbars, minimal visual noise, and immediate tactile audio feedback remove extraneous cognitive friction.

2. Flow Facilitation

Players enter an uninterrupted mental state where challenge perfectly matches skill level (r=0.74 correlation).

3. Temporal Distortion

Subjective passage of time is altered, creating deep engagement and prolonged product session duration.
